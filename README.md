# Medarot Card Robattle RB (Kabuto Ver.) — Tradução PT-BR v1.0

Primeira versão completa da tradução de **Medarot Card Robattle RB Kabuto Ver.**, o jogo de cartas dos Medabots lançado só em japonês, para português do Brasil. Funciona no **Nintendo Switch (Atmosphère)** e em **emuladores**.

## O que está traduzido

- Mais de 3.600 textos, cerca de 25 mil palavras
- História e falas dos rivais, tutorial completo, menus, telas, mensagens das partidas on-line e local, dicas de carregamento e créditos (cargos e empresas)
- Todas as cartas: nomes e efeitos de Medabots, peças, táticas, armadilhas, usinas e medalutadores, com o texto ajustado ao espaço de cada carta
- Artes com texto redesenhadas no estilo do original: prólogo, abertura da Cyberluta, «Primeiro/Segundo», telas de vitória, Medachange, versos de carta e as 31 páginas ilustradas do tutorial
- Termos da dublagem brasileira do anime: **Cyberluta**, **medalutador**, **Medaforça**, **Sr. Juiz**, **Gangue dos Robôs de Borracha**
- Nomes oficiais dos Medabots em inglês quando existem (**Metabee**, **Rokusho**, **Peppercat**, **Warbandit**…); os inéditos foram romanizados
- Texto neutro para quem joga (o jogo não marca gênero)
- Fonte nova para as letras latinas e acentos (Anta, licença SIL OFL)

## Requisitos

| | |
|---|---|
| Versão do jogo | **Kabuto Ver.** com a atualização **1.1** (`v65536`), obrigatória |
| Title ID | `0100DE4023982000` |
| Plataformas | Switch com Atmosphère · emuladores |

> ⚠️ O patch substitui arquivos da versão 1.1. Em outra versão do jogo ele pode mostrar textos errados ou impedir o jogo de abrir. A **Kuwagata Ver.** é outro jogo e não é coberta por este patch.

## Instalação

**Switch:** extraia `Medabots-RB-Kabuto-PTBR-v1.0-Switch.zip` na raiz do cartão SD.

```
SD:/atmosphere/contents/0100DE4023982000/romfs/Data/...
```

**Emulador:** botão direito no jogo → *Abrir local dos dados de mod* → extraia `Medabots-RB-Kabuto-PTBR-v1.0-Emulador.zip`.

```
load/0100DE4023982000/Medabots PT-BR/romfs/Data/...
```

Confira se o mod está marcado em **Propriedades → Complementos**.

## Observações

- Ficam como no original: o logotipo, as vozes, os nomes das pessoas nos créditos, os textos em inglês que já fazem parte do visual (WIN, New, RIVAL…) e o texto miúdo das cartas que aparecem dentro das imagens do tutorial.
- Os bordões do Sr. Juiz e o termo «Medachange» são provisórios; se alguém lembrar como eram na dublagem brasileira, avise.
